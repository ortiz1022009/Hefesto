What each version brings.

1.0.5current · November 2, 2026
New
  • New gdtoolkit component: Checks and formats GDScript without replacing Godot tests.
  • Save files: Save a file to the destination you choose without exporting the entire project.
  • Code and result: Switch between code and its result in SVG, HTML, Markdown, JSON, and CSV. HTML and SVG display without running scripts.
Improvements
  • Zoom and gestures: Images zoom without covering the bars. Pinch, drag, double-tap, or swipe without zoom to move to another image in the folder.
  • Sheets and sequences: The full image appears first. Choose a sheet with its grid or a numbered sequence; the grid highlights the actual frame and the controls are compact.
  • Titled release notes: Every item in this version has its own title and a full explanation, without repeating it or turning it into a truncated title.
  • Build cache: New Android templates let Gradle reuse tasks that have not changed.
  • Full messages: User messages are displayed in full and their text can be selected and copied.
  • Large documents: Paged documents and fewer repeated scans when opening Files and detecting projects.
  • A more complete chat: Nested lists, quotes, tasks and independently scrolling tables. Chunked reading, drafts and a recoverable queue for each conversation.
  • Code highlighting: Highlighting is expanded and prepared incrementally, without truncating long lines.
  • Compact workshop: A tidier Workshop, compact actions and the last target remembered per project.
Fixed
  • Antigravity activity: Tools report when they start and finish. A lack of activity signals is no longer blamed on model overload without evidence.
  • SVG viewer and folders: The SVG viewer keeps its controls available after an error; folders show their item count even when collapsed, without blocking the interface.
  • 64-bit emulators: Ubuntu x86_64 included in the APK to set up Linux in compatible 64-bit emulators.
  • Leaving Preview: The viewer is released when you leave Preview; returning to the app opens Chat.
  • Protected files: Large-file protection in Plan and Review, including when stopping; approved changes are preserved.
  • OpenCode responses: OpenCode no longer displays internal summaries as replies and avoids reloads for simple queries.
  • Environment and diagnostics: Actual device architecture, preservation of the previous Ubuntu base and a button to copy the log.
  • Retries and Godot: Retry asks to preserve completed work; Godot is not instructed to export unless you requested it.
1.0.4October 26, 2026
New
  • New tool uv: Python dependencies in seconds, compatible with pip and with the agent's projects.
  • Heads-up while the agent waits: if it asks for a permission or an answer while you're in another app, Hefesto sends a notification.
Improvements
  • The terminal now adapts to the keyboard: while typing, the screen ends where the keyboard begins and nothing stays hidden.
  • Ágora arranged like a store: the catalog up front; suggestions based on what you already have at the end.
  • “Installing…” in small cells: a piece's status now shows in Ágora's compact cells too.
  • The home fan is smoother: swiping through the cards no longer stutters.
  • The Ágora covers now melt into the page: each piece's color flows out of its band and reaches behind the title; the fan cards float with a soft shadow.
Fixed
  • PostgreSQL now works: it installs with one tap, Hefesto leaves the server running on the phone, and you get in with "psql" without a password.
  • Fewer snags when installing tools: the settings the built-in Linux needs are seeded automatically.
1.0.3October 25, 2026
Fixed
  • Agora tools (PHP, .NET, Godot, Chromium…) no longer trip over dbus on a clean install: the system bus now ships in Hefesto's Ubuntu base, and if a package is left half-configured the installer reconfigures and retries on its own.
  • When reporting a problem you can leave your email to get a reply.
  • If your network won't let you download the big tools (Gradle, Node, Kotlin…), you can import the official file downloaded another way: the card installs it and the store recognizes it.
1.0.2October 25, 2026
Fixed
  • The terminal starts again on phones with the old WebView — it used to stay blank: it now works on Android 8 and later, and if something fails the reason shows right on screen.
1.0.1October 24, 2026
Fixed
  • Custom OpenAI-compatible providers connect again: the "Base URL" field is now always visible, in the "Server" section next to your key — no developer mode needed. Zhipu GLM, OpenRouter or your own server work again.
1.0October 24, 2026
New
  • Hefesto 1.0 is here: the first stable version. You ask in your own words and the agent builds web pages, Android apps and Godot 4 games: it writes, runs, fixes and compiles — the APK comes straight out of your phone.
  • Inside there is a workshop: Ubuntu with a tabbed terminal, apt, Python, Node, Go, Rust and PHP. The Ágora installs tools in one tap (Godot, Blender, interpreters) and the agent uses them when needed.
  • The agent your way: Antigravity and OpenCode with your account, or Hefesto's agent with your key (OpenAI, Google, Anthropic, OpenRouter), or a local model on the phone. Review, Plan and Auto: you decide how much leash.
  • The agent looks and fixes: it sees the preview and the game, and repairs whatever fails. Git and GitHub are built in: cloning, branches, pull requests and publishing your site to Pages.
  • Built for everyday life: a free-material library with a 3D viewer, fourteen languages, the look you like, backups every few days — and lots of quality-of-life improvements in every corner of the app.
0.5.7
New
  • Godot joins Hefesto as an optional download: the agent builds complete games —scenes, code, physics— and exports them as an installable APK.
  • The models and textures coming out of Blender work straight away as game pieces: workshop and studio work together.
  • The glibc compatibility refreshes itself on already-installed environments, so Godot and Antigravity start up better.
0.5.6
New
  • Blender joins Hefesto as an optional download (≈1 GB): the agent gets a real 3D workshop inside the phone.
  • With Blender installed, the agent models and edits meshes by script, applies PBR materials, opens full .blend files and exports them to .glb and other formats.
  • The agent can render images with Cycles —real lighting and transparent background— for icons, screenshots and presentations; on the phone it runs on CPU, so big renders take a while.
  • Send it an image and the agent can turn it into 3D: terrain from heightmaps, lithophanes for the 3D printer and voxel figures from pixel art.
  • To finish them off, the agent downloads free photorealistic textures (CC0) from ambientCG —wood, metal, rock, concrete and thousands more— at no cost and no signup.
  • And it can make short cinematics: it animates objects and cameras that follow the protagonist, lights them with real sun or an HDRI, and assembles the video in batches so the phone can cope.
  • The agent now sees the videos you send: it pulls key frames and looks at them as images.
  • It also listens to attached audio (wav and mp3) when the model allows it; otherwise it tells you plainly.
  • And it looks at its own renders with the new see-image tool: if the handle came out crooked, it fixes it before showing you.
  • Modeling is faster: one environment startup per task, miniature checks, and the pretty render only when you ask for it.
  • The 3D workshop stays hot: Blender keeps running between tasks and each script goes in without reloads; when unused, it falls asleep on its own to save memory.
0.5.5
New
  • You can use the app while the agent works: what you type joins a queue above the input box and sends itself when it finishes; each queued message has its X to remove it.
  • A chip above the input box says what the agent is up to: thinking, running, building or downloading.
  • Downloads no longer block each other: they take turns, queued ones are removed with their X and the running one can be canceled.
  • If the agent finishes while you are on another tab or another app, a notification arrives.
  • The input draft is saved per chat and each project remembers the tab you left it on.
  • The screen stays awake while building; the file editor warns before leaving with unsaved changes.
  • Projects can be duplicated from their menu, and the terminal gets ↑ ↓ arrows, Ctrl-C and Tab.
0.5.4
New
  • You can send the agent images, audio, video, 3D models, ZIP and any other file: they are copied to the project and the agent reads them from there.
  • The images you send show up in the chat and open full screen when you tap them, so you can zoom with your fingers.
  • 3D models can be rotated right in the chat: glTF (.glb and .gltf), Wavefront (.obj), COLLADA (.dae), FBX, STL, PLY and 3DS, with no extra libraries in the app.
  • The only thing that isn't drawn is a .blend, which needs Blender: Hefesto saves it in the project and plainly says so instead of pretending it saw it.
  • Attaching shows a bar with what is being copied to the project, and there is a shortcut for picking audio and video.
  • If the engine you are using can't see images, the chat says so and the agent stops pretending it looked at them.
  • Videos play right in the chat: they start still on their frame with ▶, and pause on their own when scrolled off screen or after 8 minutes.
  • Office documents (Word, Excel, PowerPoint, ODF, ePub and RTF), PDFs, ZIPs, text files and fonts show a preview of their own content.
  • APKs you send show their name, version and icon without installing them.
  • The 3D viewer understands materials: colors and textures from glTF/GLB, colors from .obj with their .mtl, and diffuse color from FBX.
  • The 3D viewer has four ways to draw the model —Rendered, Solid, Wireframe and Points— plus a button to save the current view as an image and share it.
  • Solid mode is the Blender-style 'white' one: light and volume without textures or colors, to check the shape; Rendered remains the full one.
  • The full-screen image viewer can share the photo or open it with another app.
  • When the viewer can't read a model (Draco-compressed, a .blend…), it offers to convert it to a viewable format with the 3D Converter from Downloads.
  • In Settings → Performance → Attachments you choose the cap per file (25 MB to 1 GB) and how many files per message (8 to 64).
  • Only one model spins at a time in the chat to save battery, and everything starts still until you press ▶; the limit can be raised in Settings → Performance.
Fixed
  • Attached images are saved as they are, without recompressing: sprites and textures reach the project intact.
  • The viewer explains why it can't handle a model —for example, when it exceeds its memory limit— instead of just saying it couldn't be read.
  • When you scroll through the chat, models you already saw are not read from disk again: the viewer remembers the latest meshes.
  • The 3D viewer's 'Save this view' capture now shows the drawn model, not a blank frame like before.
  • Only one source plays at a time: starting a video or audio pauses whatever was playing.
  • Attachments with a preview (video, PDF, ZIP, APK, office documents, text and fonts) now have their remove button before sending.
  • A glTF whose indices cannot be read is no longer drawn deformed: the viewer drops that primitive instead of inventing triangles.
  • glTF models with sparse (patched) vertices now draw whole: before they came out streaky or stretched.
  • In full screen, the name and triangle count get their own row with the buttons below: the text no longer stacks vertically.
  • Models up to 400,000 triangles draw whole; before, anything past 120,000 was cut down to a sample and looked full of holes.
  • A model without its own colors or texture shows as neutral gray like a real part, instead of taking the theme's blue.
0.5.3
New
  • When creating a project, choose Website, App, Game (coming soon) or Undefined; Hefesto saves its type, shows it and lets you change it later.
  • Web projects have Preview and do not get APK build tools or controls; a new website already comes with its home page.
  • The project type guides each agent's examples, prompts and tools, so it works with the platform you chose.
  • Plan is shown as a document with a Goal, Steps, Files and Verification. You can edit it and run it by tapping Proceed.
  • Settings → Performance recommends a setup for your phone, lets you tune Gradle resources and turn off the environment after it sits idle.
  • Appearance offers 12 accent colors, a custom color, an adjustable gradient, pure black for OLED and a configurable interface size.
  • Accessibility adds line and letter spacing controls and an option to follow the text size you chose in Android.
  • Appearance, Accessibility and Performance are organized into collapsible subgroups; agent, Git and Downloads details take up less room.
Fixed
  • Projects, Files, Preview, chat history and Git have more breathing room and larger touch targets; Git lets you expand the list when there are many changes.
  • If an older project already had web files but no selected type, Hefesto recognizes it as a website and adapts Preview and its tools.
  • In Review, terminal commands that may change the project wait for your approval before running.
  • In Auto, explicit requests to create or fix the project are carried out with tools instead of ending as instructions or code in chat.
  • After you cancel a build, AAPT2 stays marked as installed if it is still present; you do not have to reinstall it.
0.5.2October 4, 2026
New
  • The built-in agent is now called "Hefesto (API)". It is no longer confused with "Hefesto local".
  • When a build finishes, the notice brings an Install button to install the APK without opening the app, and it says how long it took.
  • The model chip opens a panel to change it without leaving the chat: the downloaded models in Hefesto local and, in the other engines, the list with \"Default\" and a shortcut to the engine page.
  • The chat history is a panel that slides up from the bottom (like the “New project” one) and stretches up to enlarge it or down to shrink it: search, chats grouped by date (Today, Yesterday, Last 7 days, Earlier), preview and time on each one, and rename and delete in plain sight.
  • The “+” button no longer creates a chat on every tap: it opens a panel to name the chat and pick the engine, and the chat is created when you confirm.
  • Screens come and go with a short fade and slide, so they do not appear all of a sudden: the animations setting in Settings is in charge.
  • A chat message can be shared with another app -besides being copied- and a file that is already in the project can be attached, without going through the phone or duplicating it.
  • Search inside the project: a text is found in every file (not just by name), with the file and line of each match.
  • In Settings: card search -no more endless scrolling- and a breakdown of the space Hefesto uses (projects, Linux, models and cache) with what is free on the phone.
  • Downloads joins the finish of the rest: same frame, header and groups with their icon. Share any file in the project (a text, an image, a PDF) from its menu.
Fixed
  • Texts that used to show in Spanish with the app in English (engine messages, project deletion warnings and API key hints) now follow the chosen language.
  • In Hefesto local and Hefesto (API) you could not see which model was in use: now all four engines show their model next to the chat's selector.
  • Removing a tool from Downloads no longer stops halfway: what came with it is removed too, the same fallbacks as the installation are retried and, if something is still there, it says what and where it is.
  • Downloading a model no longer stops when you leave the app or turn the screen off: it keeps running in the background, with a progress bar, percentage and a Stop button in the notice.
  • A chat that had been left out of the list (an old index bug) comes back with its conversation, instead of staying lost on disk.
  • The chat history no longer comes up blank: it could say “9” and show no chat. The list is always drawn now and the chats come back, with their conversation.
  • The Files toolbar no longer clips icons on narrow screens: the essentials stay in sight (create, build and search) and the rest goes into “More”.
  • The “Search inside files” panel now closes when you tap “Close” (or tap outside): it used to stay open and you had to leave Files to get it out of the way.
0.5.1October 3, 2026
New
  • Select several projects at once and decide what to do with them: delete, pin or share them.
  • A pinned project is protected: it cannot be deleted until you unpin it.
  • Options menus (more options, attach and working modes) now match the rest of Hefesto.
  • Every window in the app (warnings, confirmations and errors) now matches the rest of Hefesto, with its own icon and the main action clearly in sight.
  • You can stop the agent or cancel the build right from the notification, without opening the app; if you stop it by accident, it asks for confirmation first and you can resume the work with one tap.
  • External engines know they run inside Hefesto: they guide you through its sections instead of sending you to a computer.
  • Notifications for finished tasks take you to the chat where it ended and clear themselves when you open the app; the working one now says what it is doing and for how long.
Fixed
  • Copying a long text (a code block, the output of a command or an error report) no longer closes the app.
  • No more ghost square peeking at the edge of Chat and Files after using the preview.
  • The back button no longer takes you to sections you already left, and leaving a project returns to the list instead of going black.
  • Agent messages are now shown with their formatting: bold, lists and code blocks with their copy button, no asterisks in sight.
  • The project list scrolls smoothly, even with many projects.
  • What's new and the rest of the texts switch language along with the app.
0.5September 30, 2026
New
  • First public version: Hefesto opens to the public. It's an agent that really works on the phone (reading and writing files, running commands, searching and building), with work modes so it warns you before touching anything.
  • Four engines: Hefesto's built-in agent, Antigravity, OpenCode and Hefesto local, a model that runs inside the phone, offline and with no keys.
  • Hefesto local: a catalogue of models to download inside the app (or import the .gguf files you already have), a three-colour notice of what your phone can handle, and settings for memory, context and processor.
  • Building on the phone: its own Linux environment inside the app (Alpine with proot, no root and no computer), APK builds with Gradle and the Android SDK, and a terminal with real commands and the error explained when something fails.
  • GitHub from the phone: connect your account, clone repositories, commit, push and open pull requests without leaving the app.
  • Files and projects: editor, file tree, search, pinned projects and backups (one project, all of them, or just the settings).
  • Language and look: Spanish and English, light and dark themes, and your settings stay saved.
  • It is in testing: when a new version opens, a notice explains what may fail and how to report it. Reporting an issue takes one tap, attaches the phone diagnostics and API keys are struck out automatically before leaving.
