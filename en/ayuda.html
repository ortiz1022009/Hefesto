Before installing

Do I need a computer at any point?
No. Writing, compiling, previewing and publishing all happen on the phone.
How much does it cost?
Nothing. There are no ads, purchases or paid version. If you use an AI provider with your key, you pay them for what you consume; Hefesto doesn't step in. Support on Ko-fi is voluntary.
Why isn't it on Google Play?
Hefesto includes a full Linux and compiles APKs; it's distributed as a signed APK from GitHub so it doesn't depend on a store's terms. The app tells you by itself when there's a new version. How to check the APK is the official one.
What phone do I need?
Android 8.0 or later and a 64-bit processor. It works on modest phones; more memory helps, especially when compiling apps and with local models. Full requirements.
How much space does it take?
The app, 67,0 MB. The first Linux setup adds around 1.5 GB. Each Ágora piece shows its size before installing, and can be removed.

The intelligence

Do I need an AI key?
For the agent, yes: your own from OpenAI, Google, Anthropic or OpenRouter; or an external agent (Antigravity, OpenCode) with your account; or a local model on the phone. Hefesto doesn't ship a key of its own nor asks for one.
Which model should I use?
Any that supports tools (function calling). Hefesto shows in Settings which of your provider's models qualify and remembers your choice per project.
Does it work offline?
Linux, the terminal, the compilers and whatever you've created, yes. The agent needs a connection unless you use a local model.
What are Review, Plan and Auto?
How much rein you give the agent. Review: asks you before every change. Plan: proposes the plan, you approve it and it runs it. Auto: works until it finishes and shows you the result.

Projects

What can I make?
Websites, Android apps, games with Godot 4 and scripts. Within each type, whatever Linux allows: Python, Node, Go, Rust, PHP, Java, C and C++, SQLite databases, FFmpeg, command-line Blender and whatever you install from the Ágora.
How do I publish a website?
Connect your GitHub account in Settings and ask “publish it”. Hefesto creates the repository, uploads the files and turns on Pages. It gives you the address.
How do I install the app I made?
When compilation finishes, “Install” appears. Android will ask Hefesto for permission to install apps the first time.
Can I continue a project I started elsewhere?
Yes: clone the repository with your GitHub account or import a compressed folder from Files.
What if the agent gets it wrong?
Every step is a card; you can undo with Git, correct it in your own words or switch to Review. You edit the project's memory file yourself to pin down what was agreed.

Data and privacy

What happens to my data?
It stays on the phone. There's no Hefesto account or server, nor usage statistics. The only thing that leaves is what you send to the AI provider you choose, to GitHub or to the sources you download from. Privacy policy.
Where are my keys stored?
In Android's encrypted store, inside the app. They're not included in exports or project copies.
How do I delete everything?
Uninstalling the app removes Linux, the projects and the keys. Before that you can export any project as a compressed file.

Common problems

The Linux setup stops halfway
It's usually the connection or the battery. Keep the screen on the first time; Hefesto resumes where it left off.
“App not installed” when opening the APK
It's almost always an earlier copy signed with a different certificate (for example, your own build). Uninstall it and install again. If it's the first time, check the phone is 64-bit.
The agent says it can't use tools
The chosen model doesn't support function calling. Switch to one marked as compatible in Settings › Intelligence.
Compiling an app takes a long time
A project's first compilation downloads dependencies and can take several minutes; the next ones are much faster. Keep Android from closing the app in the background: Hefesto shows a notification for it.
